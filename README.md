## 💾 Хранилище GitHub

### Лимиты хранилища GitHub:
- **Бесплатный аккаунт**: 1 ГБ хранилища
- **GitHub Pro**: 1 ГБ хранилища (платные дополнительные пакеты доступны)
- **GitHub Team**: 1 ГБ хранилища на пользователя
- **GitHub Enterprise**: 50 ГБ хранилища

### Как проверить оставшееся место в хранилище:
1. Перейдите в **Settings** → **Billing and plans**
2. В разделе **Storage** вы увидите использованное и доступное место
3. Или используйте команду: `gh api user | grep disk_usage` (при установленном GitHub CLI)

**Совет**: Для экономии места используйте `.gitignore` для исключения больших файлов и Git LFS для больших бинарных файлов.
